# 생보 시상정의 → 대분류(FC/법인) 매핑 규칙

**버전:** v1
**날짜:** 2026-07-11
**작성자:** 생각과 행동 (IDEA on Action)
**상태:** ✅ 적용 중 (SPEC F-056, prod 배포)
**구현:** `apps/api/src/routes/incentive-plan-definitions.ts` (`CATEGORY_FILTER.sengbo_fc / sengbo_corp`)
**관련:** 손보는 별도 규칙 → `docs/reference/sonbo-시상유형-대분류-매핑.md`

## 1. 목적

생보 시상정의를 **생보FC시상 / 생보법인시상**으로 나눠 필터링하기 위한 분류 규칙을 정의한다.

## 2. 핵심: 생보는 channel로 정확히 파생 (손보와 대비)

| 구분 | 대분류 근거 | 정확도 |
|------|------------|--------|
| **생보** (본 문서) | `channel` 필드 (FC / 법인) | **정확** (원본에 값 존재) |
| 손보 | 시상유형(cond1) 근사 + OCR 링크 | 근사치 (원본에 채널 없음) |

생보 시상정의는 원본(`시상정의_생보.xlsx`)에 **channel 값(FC / 법인)이 이미 채워져** 있어, 손보처럼 시상유형으로 추정할 필요가 없다. 매핑이 결정적이다.

> **주의**: 생보의 `cond1`(시상유형)은 대부분 `null`(7,889건)이거나 "10만이상"·"30만이상"·"월납입보험료 합산실적 5천만원 이상시" 같은 **실적 기준 금액**이다. 설계사/법인(대분류)과 무관하므로 대분류 파생에 쓰지 않는다.

## 3. 매핑 규칙

| 대분류 | 코드 | 조건 |
|--------|------|------|
| 생보**FC**시상 | `sengbo_fc` | `line_type='생보' AND channel='FC'` |
| 생보**법인**시상 | `sengbo_corp` | `line_type='생보' AND channel='법인'` |

### SQL 규칙 (SSOT)

```sql
-- 생보FC시상
line_type = '생보' AND channel = 'FC'
-- 생보법인시상
line_type = '생보' AND channel = '법인'
```

## 4. 실측 결과 (2026-07-11, 로컬 실데이터)

|--------|------|
| 생보FC시상 (`sengbo_fc`) | **5,470** |

## 5. channel=null 엣지 8건

- 전부 **동양생명**(dongyang-life). 상품: 우리WON하는보장보험(갱신형) 등, 일부는 "설계사연속가동 프로모션"(cond1="11월가동자").
- channel 값이 비어 있어 FC/법인 어느 필터에도 안 잡힌다(생보FC·생보법인 둘 다 channel 조건 필요).
- 원본 데이터 품질 이슈(채널 미표기). 필요 시 원수사 확인 후 채널 보정.

## 6. 규칙 변경 방법

생보 대분류는 `channel` 필드에 100% 의존하므로, 규칙 변경은 사실상 불필요하다. channel 값 자체를 보정해야 하면 원본 재임포트 또는 개별 UPDATE로 처리한다. 필터 코드는 `CATEGORY_FILTER.sengbo_fc / sengbo_corp`.

## 7. 한계

- channel=null 8건은 미분류(생보 대분류 필터에 안 잡힘). 데이터 정합 이슈라 매핑 규칙으로 해결 불가.
- 생보는 손보와 달리 근사치 이슈가 없다(channel 정확). 이 문서는 대칭성·인수인계용 참조.
