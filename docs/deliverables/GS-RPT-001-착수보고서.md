## 2. 추진 배경·목표

30개 원수사가 매월 서로 다른 양식의 엑셀로 송부하는 수수료·시책 내역을 AI 온톨로지 매핑으로 표준화하고, 시책 룰 적용 - 대사(차액 검증) - 월 마감 - 지급 내역서 발급까지 처리하는 통합 정산 시스템을 구축한다.

**성공 기준 (계약 합의)**

1. 양식 변환 성공률 99% 이상
2. 병행 검증 차액 0원 (저장값 vs 재계산 무결성)
3. 수만 행 파일 처리 시 비블로킹 (업로드 즉시 접수, 백그라운드 처리)
4. 운영 자립 (개발자 없이 포맷/룰 변경 가능)

## 5. 선행 구현 현황 (프로토타입)

계약 협의와 병행하여 제안 검증 목적의 프로토타입을 선행 구현·운영 중이다. 본 개발은 이 자산을 기반으로 실데이터 검증·고객 검수·보강에 집중한다.

- 구현 단위(F-item) 66건 완료, 프로덕션(https://z01.minu.best) 배포·운영 중
- 매핑 엔진·시책 룰·대사·마감·내역서 전 트랙 동작 (주요 원수사 26곳 등록)
- 시책안 OCR(CLOVA + Upstage) 실 연동, 시상정의 카탈로그 14,590건 구축
- 테스트 147건 + 브라우저 E2E, CI/CD 자동 배포 체계 가동
- 고객 데모 피드백 반영 이력: 2026-07-08 데모 시연 이후 피드백 10건+ 반영
