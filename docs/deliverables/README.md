# 산출물 대장 (Deliverables Register)

> ga-settle 프로젝트의 고객 대면 산출물 정본 대장. 정본은 이 디렉토리의 마크다운이며, 전달본(PDF 등)은 정본에서 변환한다. (F-067)
> 포털 `/deliverables` 연동은 B-020에서 이 대장을 데이터 소스로 결선 예정.

## 문서 코드 체계

`GS-{TYPE}-{NNN}` - TYPE: RPT(보고) · PLAN(계획) · TRC(추적) · HIS(이력)

## 날짜 placeholder 규약

- 계약 시작일 미정 상태로 작성됨. 모든 문서의 일정은 `{{CONTRACT_START}}`(W1 월요일) 기준 상대 주차(W1~W15)로 표기한다.
- 계약 확정 시 이 파일과 각 문서의 `{{CONTRACT_START}}`를 실제 날짜로 일괄 치환하고 버전을 올린다 (`grep -rn 'CONTRACT_START' docs/deliverables/`).

## 운영 규칙

1. 문서 수정 시 대장의 버전·상태를 함께 갱신한다.
2. 고객 전달 시점에 전달일을 기록하고 상태를 `전달`로 변경한다.
3. 상태: 초안 → 내부검토 → 전달 → 확정 (고객 승인)
