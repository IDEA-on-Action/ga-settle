## 1. 목표

30개 원수사의 상이한 엑셀 양식을 AI 온톨로지 매핑으로 표준화하고, 수수료·시책 정산 - 대사 - 마감 - 지급 내역서까지 단일 시스템에서 처리한다. 정량 목표: 변환 성공률 99%+, 병행 검증 차액 0원, 수만 행 비블로킹, 운영 자립.

## 2. 범위

**포함**: 업로드 파이프라인(멱등·원본 보관) / AI 매핑(L0~L4) + 사람 확정(HITL) / 시책 룰 엔진·시뮬레이션 / 시책안 OCR 등록·시상정의 카탈로그 / 대사·수동 보정·월 마감(이중 잠금) / 지급 내역서·이체 CSV·집계 / 계정·RBAC·OTP·감사 로그 / 골든 회귀·병행 검증 / 운영 이관

**제외 (후속 협의)**: 원수사 API 직접 연동, 설계사 개인 조회 포털 고도화, 대사 차액 원인 LLM 자연어 설명 등 (내부 Backlog 관리, 계약 범위 외)

## 3. 시스템 구성

| 계층 | 기술 | 비고 |
|------|------|------|
| 프론트엔드 | React 18 + Vite + TypeScript(strict) + Tailwind | SPA, TanStack Query |
| API | Cloudflare Workers + Hono + Zod | 서버리스, 전역 인증 게이트 |
| 비동기 처리 | Cloudflare Queues | 엑셀 파싱·OCR 백그라운드 처리 |
| 데이터 | Cloudflare D1 (SQLite) + Drizzle | 18개 엔티티, 트리거 이중 잠금 |
| 파일 보관 | Cloudflare R2 | 원본 불변 보관, 마감 스냅샷 |
| AI | Claude API (매핑 후보) + CLOVA OCR + Upstage (시책안 구조화) | 폴백: 규칙 기반 엔진 |

**AI 매핑 5단계**: L0 시그니처 캐시(재등장 양식 즉시 매핑) - L1 데이터 프로파일링 - L2 LLM 시맨틱 매핑 - L3 정합성 검증(지급수수료 ≈ 보험료 x 수수료율) - L4 신뢰도 등급.

## 4. 개발 원칙 (불변)

1. **역추적**: 모든 정산 숫자는 원본 파일의 행까지 역추적 가능 (upload_id + row_no)
2. **마감 이중 잠금**: 마감된 정산월은 API와 DB 트리거 양쪽에서 변경 차단, 스냅샷 보관
3. **AI는 후보/근거만**: 정산 숫자는 전부 결정적 코드가 계산. LLM은 매핑 후보·설명·초안만 제시하고 확정은 정합성 검증 또는 사람(HITL)
4. **멱등**: 동일 파일 중복 반려, 배치 재실행 안전
5. **민감정보 보호**: 금액·인적정보 필드 암호화, LLM 전송은 마스킹 표본만 (컬럼당 8개 한정)
6. **골든 회귀**: 정산·매핑·룰 로직 변경 시 골든 표본 회귀 테스트 필수 통과

## 5. 개발 방법론

- **명세 주도(SDD)**: 명세(SPEC) ↔ 코드 ↔ 테스트 삼각 동기화. 모든 작업은 구현 단위(F-item)로 등록 후 착수
- **스프린트**: 1~2일 단위 스프린트, 완료 시 CI 통과 + 프로덕션 배포 + 실측 검증까지 포함
- **HITL 우선**: 매핑 확정·룰 승격·가족계약 확정 등 판단 지점은 담당자 확정 절차 내장
- **선행 구현 활용**: 프로토타입(66 F-item, 프로덕션 운영 중)을 기반으로 본 개발은 실데이터 검증·검수·보강 중심 진행

## 7. 품질 보증

- **CI 게이트**: 전 변경 push마다 lint + typecheck + 단위/통합 테스트(147건+) + 브라우저 E2E 자동 실행, 실패 시 배포 차단
- **자동 배포**: main 병합 시 D1 마이그레이션 - 빌드 - 배포 - 헬스 스모크까지 자동 (수동 배포 갭 구조적 차단)
- **병행 검증**: 저장된 정산 결과 vs 재계산 결과 차액 0원 무결성 검증 API 상시 제공
- **골든 회귀**: 원수사 표본·기대 결과 데이터셋 기반 회귀 테스트

## 8. 보안·컴플라이언스

- 세션 인증 + 역할 기반 접근 제어(RBAC), @atasset.co.kr 계정 이메일 OTP 로그인 (프로덕션 활성)
- 금액·인적정보 필드 암호화, LLM 전송 페이로드는 마스킹 표본 한정
