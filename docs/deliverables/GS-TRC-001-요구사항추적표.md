## 4. 유지 규칙

1. 내부 SoT는 SPEC.md - 신규 요구사항은 SPEC REQ로 먼저 등록되고, 본 추적표는 마일스톤 시점마다 재파생한다.
2. FR/NFR 변경(고객 합의)이 생기면 PRD 개정 → SPEC REQ 갱신 → 본 표 갱신 순서를 지킨다.
3. 상태 범례: ✅ 구현 완료 · 🔧 진행 중 · 📋 계획 · ⏸️ 보류(사유 기재).
