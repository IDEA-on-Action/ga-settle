시책안 OCR과 시책룰에 대해 상세히 정리해 주신 피드백 5가지를 모두 반영해 시스템에 적용을 마쳤기에 안내드립니다. 특히 손해보험 시책안이 인식되지 않던 부분은 원인을 확인해 해결했습니다. 지금 바로 확인하실 수 있습니다.

■ 이번에 반영한 내용

1. 손해보험 시책안(여러 페이지 PDF) OCR 오류 해결
   - 손보 시책안이 12개 이상 시상으로 12페이지를 넘으면서 "No more than 10 pages" 오류로 인식되지 않던 부분입니다.
   - OCR 엔진이 한 번에 10페이지까지만 처리하는 제약이 원인이었습니다. 이제 시스템이 긴 PDF를 자동으로 10페이지 단위로 나눠 인식한 뒤 결과를 합치도록 보완했고, 페이지 수와 관계없이 인식됩니다.
   - 다만 이 부분은 실제 5월 1·2주차 손보 시책안 PDF로 함께 한 번 확인해 보면 가장 확실합니다. 오류가 났던 두 파일을 회신에 첨부해 주시면 실제 인식 결과를 바로 확인해 드리겠습니다.

2. 생명보험 납입기간별 지급율 반영
   - "상품 납입기간별로 지급율이 다른데 반영이 안 된다"고 주신 부분입니다 (예: ABL생명 5년납 익월 150%·13차월 0%, 7년납 익월 250%·13차월 100%).
   - OCR 결과 화면에 '납입기간별 지급율' 표를 추가해, 납입기간·지급시점별로 서로 다른 지급율을 각각 별도 행으로 추출해 보여드립니다.

3. 시책룰 등록 항목 확대
   - 실적인정기분·환수기준(1차년도·2차년도)·예외적용·구간시상·브릿지시상 항목을 시책룰 등록 화면에 추가했습니다.
   - 특히 구간시상은 실적 구간별로 지급률이 달라지는 계산까지 반영했습니다. 실적인정·환수·예외·브릿지 항목은 담당자 확인과 감사 근거로 함께 기록됩니다.

4. 시책룰 삭제 시 시상정의 확정 복원
   - "시책룰을 삭제하면 해당 시상정의 확정을 후보로 되돌려야 한다"고 주신 부분입니다.
   - 시책룰을 삭제하면 원본 시상정의가 자동으로 '후보' 상태로 복원되어, 다시 확정·승격하실 수 있도록 했습니다.

5. 시책안 업로드 시 대분류 먼저 선택
   - 시책룰이 손보설계사시상·손보자체시상·생보FC시상·생보법인시상 4개 대분류로 나뉜다는 점을 반영했습니다.
   - 시책안 업로드 화면에서 4개 대분류 중 하나를 먼저 선택한 뒤 업로드하도록 했고, 등록 내역에도 대분류가 함께 표시됩니다.
