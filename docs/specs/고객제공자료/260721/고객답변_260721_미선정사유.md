## 분석

### 사실 정리

| 항목 | 내용 |
|------|------|
| 기술 평가 | "기술이나 개발이력은 탁월, 모두가 만족" - 실무진 평가는 최상 |
| 미선정 결정 주체 | 에이티에셋 대표(경영진). 실무진("저희도 같이 하고 싶었는데요")과 온도차 명확 |
| 미선정 사유 (단일·핵심) | 서민원 대표가 **타 기업 재직 중** → "업무 소통이 원활하지 않을 것"이라는 경영진의 우려 |
| 중개(위시켓) 입장 | 재직 중이어도 소통 원활·개발기간 단축 가능하다고 옹호했으나 미수용 |
| 관계 종결 톤 | 우호적. 감정적 갈등·품질 불만·가격 이슈 전무 |

### 해석

1. **기술·성과는 반박된 것이 없다.** 데모 12일 구축, 피드백 10건+ 당일 반영, 산출물 5종까지 실측으로 보여줬고 실무진 만족도 확인됐다. 미선정은 산출물 품질과 무관한 **리스크 인식 문제**다.
2. **"겸업 리스크"는 실적으로 반증 가능한 우려였으나, 경영진 의사결정 단계에 그 실측 증거가 전달되지 않았거나 전달돼도 프레임을 못 바꿨다.** 협의 기간 내내 소통·속도는 오히려 강점이었다(당일 반영 이력). 실무진↔경영진 사이에서 우리가 직접 경영진을 설득할 접점이 없었던 구조적 한계.
3. **재발 가능성 높은 구조적 반대 사유다.** B2B 수주에서 "대표 겸업"은 앞으로도 최종 결재 단계에서 같은 방식으로 걸릴 수 있다. 실무 검증을 통과해도 경영진 리스크 심사에서 떨어지는 패턴.
4. 답변이 정중하고 문을 닫지 않는 톤("곧 다른 업체와 함께 하실 수 있으리라") - 향후 재접촉 여지는 남아 있다.

### 향후 대응 옵션 (타 수주 건 공통)

1. **초기 단계에서 선제 프레이밍**: 겸업 사실을 숨기지 말되, "전담 소통 채널 + 응답 SLA(예: 평일 N시간 내) + 실측 이력(당일 반영 사례)"을 제안서에 명시해 경영진 심사 단계용 반박 자료를 실무진에게 미리 쥐여준다.
2. **경영진 접점 확보**: 데모/시연 단계에서 최종 의사결정자 배석을 요청 - 실무진 경유 전달의 프레임 손실 방지.
3. **체제 보강 카드**: 규모 있는 계약에서는 검수·소통 백업 인력(파트너/외주) 명시로 "1인 겸업" 단일실패점 우려 해소.
4. **에이티에셋 관계 유지**: 파기 확인서 서명·발송을 깔끔히 이행하고 짧은 감사 회신으로 종결 - 차기 니즈(운영 자립 실패, 타 업체 이슈) 발생 시 재접촉 여지 보존.
