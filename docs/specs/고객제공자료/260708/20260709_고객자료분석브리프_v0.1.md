## 2. 핵심 관찰

### 시상 체계 구조
- 이원 체계: ①보험사→GA 시상(시상정의 엑셀·PPT 시상안) ②GA 자체 시상(자체시상 PDF).
- 시상 유형: 기본시상(보험료×지급률), 주차시책(월초P×배수, 기간 3구간), 주력상품 프로모션, 신상품, 구간 프로모션(합산 보장월초 구간별 정액), 연속가동, 물품시상(에어프라이어·금 등 현물).
- 지급 시점 다양: 익월 / 13차월 / 15차월 / 2차년 — 유지·환수 조건과 연동.
- 조건 차원: 상품×납입기간×지급시점×FC/법인×적용지점×실적구간. 본인·가족계약 제외, 건당 보험료 한도(25만), 비월납 제외, 미유지 환수 등 예외 규칙 다수.

### 데이터 품질 이슈 (시스템화 관점)
- 손보 시상정의는 318열 가로 확장형 비정형 — 정규화 필요. 생보는 이미 세로형으로 정리되어 있어 스키마 참고 기준으로 적합.
- 주차별 시상안의 원천이 이미지 포스터라 규칙 입력은 수작업(또는 OCR) 의존.
- 월중 수시 개정(생보 3월에만 4회) → 버전 관리·적용 시점 이력 필수.
- 고객 화면 캡처 기준, 현재 정산은 엑셀 수작업(보험사별 탭 + 피벗 + 검증 시트, 월 1,475건/2.4억 규모)으로 운영 중.

## 3. 제안 방향 시사점

1. 예상 과제: 보험사별 시상 정의 등록 → 실적 매칭 → 시상금 산출 → 검증/정산까지의 자동화(현행 엑셀 대체).
2. 핵심 난점: 시상 규칙의 비정형성·수시 개정·현물 시상·환수 로직. 규칙 엔진(기준월+적용기간 버전 관리) 설계가 관건.
3. 참조 스키마: 생보 시상정의 16열 구조(기준월/보험사/상품/납기/지급시점/채널/지점/조건/적용률)를 손보까지 확장하는 통합 모델 제안 가능.
4. 확인 필요(발주자 문의 후보): 실적 원천 데이터 형식(보험사 수수료 명세?), 시상정의 입력 주체, 대상 사용자(정산 담당/지점/FC), 기존 시스템 유무.
