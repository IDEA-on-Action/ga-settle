김혜경 차장님, 안녕하세요. 생각과 행동입니다.

오늘 데모를 직접 사용해 보시며 주신 피드백을 반영해 시스템에 적용을 마쳤기에 안내드립니다. 통화에서 말씀 주신 4가지 모두 실제 화면에 반영되어, 지금 바로 확인하실 수 있습니다.

■ 이번에 반영한 내용

1. 시책룰 화면에서 시상정의 흐름이 한눈에 보이도록 보완
   - "매월 시상 자료를 확정하면 그 리스트를 시책룰에서 볼 수 있는가"라고 물어봐 주신 부분입니다.
   - 시상정의(귀사가 주신 원본 카탈로그, 14,590건)와 실제 정산에 쓰이는 시책룰은 안전을 위해 분리되어 있고, 담당자가 확정·승격한 것만 시책룰로 올라갑니다.
   - 그 연결 고리가 화면에서 잘 드러나지 않아, '시책 룰' 화면에 시상정의 건수와 함께 "확정 화면으로 이동" 안내를 추가했습니다. 이제 시책룰 화면에서 바로 시상정의 확정 화면으로 넘어가 승격하실 수 있습니다.

2. 시책안 PDF·이미지 업로드 경로 추가
   - 업로드 화면에 원수사 엑셀만 있던 것을, '지급명세 엑셀'과 '시책안 문서(OCR)'를 구분해 올리실 수 있도록 했습니다.
   - '시책안 문서'로 올리시면 PDF와 이미지(PNG·JPG) 모두 지원하며, OCR이 지급률·적용기간·대상 등 시책룰 항목 후보를 자동으로 추출해 보여드립니다. 확인·보정 후 시상정의로 확정하시면 됩니다.
   - 실제 시책안 PDF 파일로 한 번 올려보시고 인식 결과를 함께 확인해 주시면, 파일 형태에 맞춰 더 다듬어 드리겠습니다.

3. 대시보드의 지난 테스트 파일 정리
   - 7월 정산월에 남아 있던 테스트 업로드 자료를 정리했습니다. 이제 깨끗한 상태에서 실제 자료로 확인해 보실 수 있습니다.

4. 업로드 내역 삭제 기능 추가
   - 업로드 화면 아래 '업로드 내역'에서 올리신 파일을 직접 삭제하실 수 있습니다.
   - 실수로 올린 파일이나 테스트 자료를 담당자가 바로 정리하실 수 있고, 삭제 시 관련 계산 자료까지 함께 정리됩니다.
   - 안전장치도 함께 넣었습니다. 이미 마감된 정산월의 자료는 삭제되지 않도록 보호되며, 모든 삭제는 처리자·시각이 감사 기록으로 남습니다.
